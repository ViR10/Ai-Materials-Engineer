# AI Materials Journey

Materials Engineering se AI Engineering ki taraf mera safar — Python, Data Science, aur Machine Learning seekh kar Materials Informatics mein specialize karna.

## Day 1: Python Fundamentals + Material Database

### Kya seekha:
- Variables, Data Types (int, float, str, bool, list)
- Functions (reusable calculations jaise density, stress)
- Loops (batch processing samples)
- Classes (Material aur MaterialDatabase objects)
- Exception Handling (crash-proof code)
- File Handling (permanent data storage)

### Project: Material Database
Ek command-line application jo materials ka data manage karta hai:
- Add / Delete / Search materials
- Density, Hardness, UTS store karta hai
- Data `.txt` file mein permanently save hota hai

### Kaise Run Karein
```bash
python material_database.py
```

### Files
- `material_database.py` — main program
- `materials_data.txt` — saved data (auto-generated)
